# Screenshots and figure redraws for the paper

This folder holds the five figures the paper cites, as **PNG (300 dpi, drop
straight into Word)** and **SVG (text kept as text, so Figma / Canva /
Illustrator / Inkscape can edit every label)**. Sources are `svg.fonttype: none`
matplotlib outputs generated by `tools/make_figures.py` in the Arena workspace —
the numbers in them are read off the code, so if you redraw a figure, keep the
values identical or the paper stops being true.

## Files

| File | Cited in | What it asserts |

| `fig2-data-model.svg/.png` | §4.2 | 16 collections; solid edges are id or uid references, the four dashed amber edges are display-name references |
