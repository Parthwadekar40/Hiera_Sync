# Paper bundle (built artefacts)

These are generated from \`docs/RESEARCH_PAPER.md\` so they can be downloaded without a sandbox
server. Regenerate with the exporter (\`md → docx/html\`, \`markdown\` tables → \`xlsx\`);
the figure and table sources themselves live in \`docs/figures/\` and \`docs/tables/\`.

| File | What it is |
|---|---|
| \`RESEARCH_PAPER.docx\` | Word build: A4, Times New Roman, 8 real tables, Figs. 1–5 embedded |
| \`RESEARCH_PAPER.html\` | Print-ready HTML — open it and Ctrl/⌘+P → Save as PDF |
| \`paper-tables.xlsx\` | every table from the paper, one sheet each, restyle freely |

Do not hand-edit these; edit \`docs/RESEARCH_PAPER.md\`, \`docs/figures/\` and rebuild. Binary
build output — safe to delete from the branch once the paper is submitted.
